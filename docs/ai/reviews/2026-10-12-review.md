# Deep review (full findings)
Lead spot-checked F1, F3, F5, F6, F7 in code: all confirmed.

## Verdict
Code is tidy; GOTCHAS guards intact (no hook_key/unhook_all, PhotoImage master=, overlay clears _default_root, model never in main process). Weak spot: dictation-session teardown on failure/slow paths. #1: default toggle mode + duck=mute -> a model-load failure leaves system audio muted until quit. #2: release pipeline floats all deps; CI resolves customtkinter 6.0.0 (dev venv 5.2.2), smoke never touches UI. #3: no public release contains whisper.cpp/Vulkan though AMD support is advertised.

## Findings
- F1 HIGH: model-load failure (toggle) leaves audio muted — main.py:180-183 activate() ducks after start; transcriber.py:197-206 worker failure sets _running=False, never restores volume/overlay/tray; next Alt+Q re-activates and mutes again. Hold mode unaffected.
- F2 HIGH: final text dropped or injected into next dictation if last transcription >5 s — transcriber.py:365-367 stop() join(timeout=5); main.py:203-206 reads _pending_text immediately; flush transcribes whole buffer beam 5 (CPU paths slow); late _on_complete appends into next session. ModelHost._io held up to 600 s during reload.
- F3 HIGH: model-host replies desync after transcribe timeout — model_host.py:244-248 no kill on timeout; next transcribe reads stale 'segments'; off-by-one forever. Child death -> silent [] (238-239, 247-248).
- F4 HIGH: release deps float; customtkinter 6.0.0 (2026-06-24) vs tested 5.2.2, ~1300-line diff incl. CTkToplevel bind_all, CTkFont cget; Eqho uses private attrs (_parent_canvas, _fg_color, _text_label, _get_widget_scaling in src/ui/widgets.py, dashboard.py:587). CI Python 3.11 vs dev 3.13 (numpy 2.5/av 19 need >=3.12). Whether 0.8.8 shipped with ctk 6: UNVERIFIED (logs expired).
- F5 HIGH: public releases lack whisper.cpp — release.yml installs only requirements.txt (pywhispercpp commented); spec bundles only if installed (eqho-win.spec:24-44). Site/CHANGELOG 0.8.2 claim AMD/Vulkan bundling.
- F6 MED-HIGH: macOS paste sends Ctrl+V — injector.py:68-71 Key.ctrl hardcoded; clipboard restored 0.1 s later -> dictation lost; restore races slow apps; non-text clipboard wiped.
- F7 MED: model pick raises AttributeError — ui/dashboard.py:519 self.ctx vs self._ctx (since v0.8.0, 7161887); preload/engine reconcile/model_changed subscribers never fire; stale comment ui/tabs/models.py:341-343.
- F8 MED: first-run model download must finish within 600 s load timeout (model_host.py:24,225); ~1.5 GB distil-large-v3 fails on <~20 Mbit/s; combines with F1.
- F9 MED: settings writes non-atomic, unlocked from 3 threads (settings.py:232); load() catches only JSONDecodeError/TypeError — truncated -> defaults then overwrite; non-object JSON/bad encoding crash startup; no type coercion.
- F10 MED (privacy): transcripts logged at INFO regardless of history_enabled — main.py:230, transcriber.py:318,353.
- F11 LOW-MED: CI actions on deprecated Node 20 (checkout@v4, setup-python@v5, upload-artifact@v4, action-gh-release@v2; withastro/action@v3). Site fine (base /eqho); Astro 4.16.19 advisories SSR-only.
- F12 LOW: AppImage autostart uses sys.executable in /tmp/.mount_* (oskit/base.py:173-174, linux.py:98) -> use $APPIMAGE; App.restart() dead code (main.py:334-371) would orphan host child; ui/tabs/models.py:131-136 sys.platform outside oskit; Pillow 12.1.1 bundled-assets only (12.3.0 available); prior docs/winget drift stands.
